저장소 루트에서 실행합니다. 이 작업 환경의 경로는 `/home/rheehose/renewsejongpac`이며,

## 내부 이용 흐름과 인터랙션 (2026-10-16)

- **방문 준비:** 출발 역·주차장과 목적 공간을 선택하면 같은 화면의 개략도와 이동 순서가 바뀝니다.
  선택값은 주소에 보존되며 공간·접근성 안내로 이어집니다.
- **자료 열람:** 기존 프로그램·공간·예술단 데이터와 이용 안내로 구성한 8종의 시연 자료를
  검색·분류하고, 본문 표와 같은 데이터를 CSV로 내려받습니다.
- **이벤트:** 현재 브라우저에 저장한 응모를 행사·접수번호로 조회하고 실제 저장·철회 상태를 확인합니다.
- **채용:** 공고에서 지원서 작성·검토·수정·로컬 저장으로 이동하고 신청내역에서 확인·철회합니다.
- **굿즈:** 3개 상품의 상세·수량 선택, 장바구니 수정·삭제, 주문 검토·저장, 주문내역·취소를 제공합니다.
  신규 등록 경로는 채용 지원 1개, 굿즈 상세 3개, 장바구니·주문내역 2개입니다.

138개 경로와 공통 컴포넌트를 검토해 제목 260ms, 편집 문구 320ms, 미디어 430ms,
목록 220ms의 진입을 역할별로 적용합니다. 화면 밖 내용은 보일 때 한 번 실행하며,
목록의 순차 지연은 최대 105ms로 제한합니다. 홈은 기존 히어로를 유지합니다.
메뉴·검색 모달, FAQ·신청내역 펼침, 프로그램 분류·탭·공유·검색 결과, 예매·신청 단계와 완료,
관심·알림·버튼, 맨 위로 버튼에도 상태별 모션을 적용합니다.
필터·삭제로 남은 항목은 220ms로 위치를 연결하고, 공유 패널은 160ms 열기·120ms 닫기를 사용합니다.
달력의 월 이동은 포인터 조작에 200ms 방향 전환을, 키보드에는 위치 이동 없는 전환을 제공합니다.
길찾기는 강조선만 240ms로 그립니다. 수량·가격은 정확한 값을 즉시 표시한 뒤 짧게 명도를 전환합니다.
빠른 반복 입력은 진행 중 동작을 교체하고, 모션 감소 설정은 실행 도중 변경해도 반영합니다.
키보드 포커스·닫힌 영역의 접근·경로 이동 시 정리를 함께 처리하며 추가 라이브러리를 사용하지 않습니다.
좌석·입력값·표·정책 본문은 조작·읽기 위치를 유지합니다. 필터 갱신과 새 상세 화면 이동을 구분하며,
부분 목록 교체 때도 이전 관찰 대상을 정리합니다. 펼침 도중 Tab으로 진입하면 즉시 높이를 확정합니다.
기존 히어로와 방문 미리보기의 전환 계약은 보존합니다.

방문 안내 우측 공통 미리보기의 그림자는 `0 8px 24px rgb(17 20 38 / 10%)`로 줄였습니다.
하나의 프레임, 목록 범위 안의 세로 중앙 고정, 마지막 이미지 유지 동작은 동일합니다.
정지한 포인터 아래로 스크롤하며 항목이 바뀌는 동작도 확인했습니다. 내부 이미지가 프레임보다
커져 삽화 아래가 잘리던 문제를 수정해 이미지 경계를 맞췄습니다. 원본은 즉시 이미지를 교체하지만,
v3의 240ms 교차 전환은 사용자가 요청한 부드러움을 위한 동작입니다.

체험 데이터는 `sejong-v3:`로 분리하여 현재 브라우저에 저장합니다. 실제 인증·결제·배송·티켓 발행·
기관 접수·당첨 추첨은 수행하지 않습니다. 길찾기는 보유한 안내와 개략도를 사용하는 방문 준비 기능이며
실시간 경로·도착 시간·교통 상태를 계산하지 않습니다. 공개자료는 시연 데이터이고 공식 공시·재무 실적이 아닙니다.
앱에 백엔드나 외부 결제·지도 서비스를 새로 연결하지 않았습니다.
이미지·폰트의 출처와 권리 고지는 [이미지 안내](assets/images/README.txt), [폰트 안내](assets/fonts/README.md)를 따릅니다.

## 포스터 관심 버튼 위치 (2026-10-15)

관심 하트는 포스터 이미지의 오른쪽 아래에서 각각 12px 떨어진 위치에 둡니다.
이미지와 같은 3:4 비율의 버튼 영역을 링크 밖에 두어 제목·날짜·장소의 줄 수가 바뀌어도
위치가 유지됩니다. 버튼 영역의 빈 곳은 이미지 링크 클릭을 가로막지 않습니다.

카드 아래 글까지 hover/focus 영역으로 유지하며, 하트는 위치 이동 없이 opacity만 전환합니다.
터치에서는 항상 보이고, 키보드 Tab으로 접근할 수 있으며, 버튼 조작은 상세 페이지로 이동하지 않습니다.

이번 변경은 v3의 공통 카드와 스타일에 한정했습니다. 새로 실행한 Node 테스트 16개,
v3 브라우저 264개 경로·화면 조합 및 14개 검사 그룹, 기존 카드·캐러셀 검사가 통과했습니다.
별도 브라우저 확인에서는 홈·전체 프로그램·공연 목록의 모든 카드에 대해
320·390·768·1024·1440px에서 아래·오른쪽 여백 12px와 관심 등록·해제, 상세 링크를 확인했습니다.
검증 환경은 로컬 Google Chrome과 `/tmp/sejong-validation`의 Playwright입니다.

```bash

NODE_PATH=/tmp/sejong-validation/node_modules CHROMIUM_PATH=/opt/google/chrome/chrome SEJONG_TEST_URL=http://127.0.0.1:8000/v3/index.html node v2/tests/cards-carousel.cjs
```

## 방문 안내 이미지 미리보기 (2026-10-15)

‘예술을 만나는 길, 편안하게 오세요.’의 네 링크에 마우스를 올리거나 키보드로 포커스하면
해당 안내 이미지로 전환합니다. [NEWBIRD 홈페이지](https://newbird.co.kr/)의 INSIDE 목록을
브라우저에서 직접 확인해 공통 이미지의 전환·스크롤·유지 동작을 적용했으며,
기존 문구·목적지·흰색 화면·사진 영역의 배치를 유지합니다.

오시는 길은 기존 건물 외관, 공간과 좌석은 대극장 객석, 접근성과 관람 안내는 저장소에
보존된 해당 안내 삽화를 사용합니다. 사진과 삽화의 구분은 대체 텍스트에도 명시합니다.
이미지 영역은 같은 4:3 크기를 유지합니다. 큰 사진은 200ms, 우측 공통 미리보기는 240ms의
opacity 전환을 사용합니다.
모션 감소 설정에서는 전환 효과를 끄며, 터치에서는 링크를 한 번 눌러 원래 목적지로 이동합니다.
이미지 로딩에 실패하면 이전 이미지를 유지하고, 빠른 입력에서는 마지막 항목만 반영합니다.

큰 기본 사진을 유지하고 **텍스트 오른쪽의 공통 미리보기 한 영역**을 사용합니다.
항목마다 별도 이미지 창을 만들지 않으며, 항목을 옮겨 가리킬 때 같은 프레임 안의 이미지만
교차 전환합니다. 처음에는 첫 이미지를 표시하고, hover·키보드 포커스를 벗어나도 마지막
이미지를 유지합니다. 스크롤 중에는 목록 범위 안에서 화면 세로 중앙을 따라가며,
고정 헤더 아래 공간을 확보하고 프레임 밖은 잘라냅니다. 800px 이하 또는 터치 중심 화면에서는
공통 미리보기를 숨기고 기존 큰 사진과 한 번 누르는 링크를 유지합니다.

```bash
NODE_PATH=/tmp/sejong-validation/node_modules CHROMIUM_PATH=/opt/google/chrome/chrome node v3/tests/visit-preview.cjs
```

새 검사는 hover·Tab/Enter, 네 이미지 대응, 크기 유지, 마지막 이미지 유지, 빠른 전환, 모션 감소,
다섯 화면 폭의 가로 넘침, 홈 재진입, 터치 한 번 이동을 확인합니다.
