## 추가 사용자 흐름

- `#/booking/:programId`: 공연은 날짜·시간 → 좌석 → 할인·확인 → 완료, 전시는 날짜·시간 → 입장 인원 → 할인·확인 → 완료
- `#/apply/education?program=:programId`: 수강 신청 → 검토 → 완료
- 12개 대관·단체·문의·후원·이벤트 등 신청 유형은 작성 → 검토 → 완료를 포함합니다.
- 프로그램 상세 탭, 목록/달력, 매거진 호별 기사, 정보공개 문서 등은 해당 주소의 쿼리로 직접 접근할 수 있습니다.
