# 세종문화회관 신버전 설계

## 방향과 근거

2026-10-15 요청에 따라 로컬 `skills/lemonade/SKILL.md`와 Toss/Sejong 프로필, 코드·마크업, 상호작용, 구현 검수 지침을 적용합니다. 토스의 큰 제목·여백·명료한 행동, 세종문화회관의 작품 중심 구성·정렬된 일정·편집 그리드를 조합합니다. 프로필의 보관 자료 분석을 참고했으며 현재 공식 사이트를 새로 실측한 결과는 아닙니다.

와이어프레임은 정보 구조의 근거입니다. 이미지 자리 표시자, 임시 색, 반복된 패널 모양을 완성 디자인으로 복제하지 않습니다. 기존 정적 HTML/CSS/ES module 구조와 프로그램·예매·신청 데이터를 보존합니다.

## 디자인 토큰

구체적인 글자 크기·조작 크기·상태·문구 기준은
[디자인 기본값](design-system.md)과 `styles/defaults.css`를 따른다.

- 검정 `#000000`, 흰색 `#ffffff`를 정보와 여백의 기본값으로 사용합니다.
- 천 `--sky: #54c8e8`, 지 `--earth: #c36d15`, 인 `--human: #ffe800`을 독립 채널로 제공합니다. 새 팔레트에서는 세 변수만 바꿀 수 있습니다.
- 밝은 브랜드 색 위에는 검정 글자, 어두운 영역에는 흰색 글자를 사용합니다. 색만으로 선택·상태를 전달하지 않습니다.
- 한글·라틴은 로컬 Pretendard Variable 웹폰트와 시스템 sans-serif 폴백을 사용합니다.
- 최대 본문 폭 1320px. 제목·본문·보조정보의 역할을 나누고, 포스터의 글자와 비율을 보존합니다.
- 버튼과 이미지에 제한적인 반응형 radius를 적용합니다. 영역 전체를 둥근 카드로 만들지 않습니다.

## 구현과 범위

- 루트 `index.html`은 버전 선택, `legacy.html`은 기존 앱, `v2/index.html`은 신버전입니다.
- 공통 이미지 `assets/images/`는 두 버전이 공유합니다. 신버전의 폰트·코드·스타일은 `v2/` 안에 있습니다.
- `styles/compat/`은 기존 상세 화면·신청 흐름의 CSS 호환 기반입니다. 신버전 토큰·컴포넌트·기능 스타일을 그 다음에 적용합니다.
- 신버전 저장소는 `sejong-v2:` 접두사를 사용해 구버전 체험 데이터와 분리합니다.
- 첫 접속과 페이지 이동 시 한·영 비공식 알림을 제공합니다. 실제 인증·결제·티켓 발행은 수행하지 않습니다.

## 확인 기준

1440/768/390/320px, 한글 실제 폰트, 포스터 크롭, 가로 넘침, 메뉴·검색·필터·달력·관심·예매 흐름, 키보드 포커스, 모션 감소를 확인합니다. 스크린샷과 실패·수정 근거는 `.lemonade/`에 보관하고 최종 확인 결과는 검수 문서에 기록합니다.
