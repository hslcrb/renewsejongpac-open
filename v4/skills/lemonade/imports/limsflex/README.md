# limsflex · 림스플렉스

`limstandards`에서 파생된 웹 UI 스킬입니다. 색상·형태·레이아웃 등 시각 디자인은 자유롭게 정하면서, 코드 형식과 웹 표준은 엄격하게 지킵니다.

- 4칸 들여쓰기와 새 클래스 이름의 kebab-case 표기
- 의미에 맞는 HTML 구조, 접근성, 반응형 Flexbox·Grid 레이아웃
- 제공된 [기본 CSS](assets/default.css)를 프로젝트에 맞게 수정하거나 자체 기본 CSS로 교체 가능
- 관련 콘텐츠의 의미 있는 그룹화와 고유한 URL fragment ID

시작점은 [SKILL.md](SKILL.md)입니다. 구현할 때는 [코드·웹 표준 규칙](references/code-contract.md)을, 마무리할 때는 [검수 항목](tests/acceptance.md)을 확인하세요.

이 저장소는 공개 `firstclass` 저장소의 `.AGENTS/skills/limsflex` 경로에 연결된 비공개 Git 서브모듈입니다.
