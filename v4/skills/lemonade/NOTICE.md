## Supplied limsflex material

The user-supplied limsflex code-convention guide, references, acceptance scenarios,
baseline CSS, logos and agent metadata are preserved in the separate
[readable import](imports/limsflex/) and [original-path ZIP](imports/limsflex-originals.zip).
The [manifest](library/limsflex-manifest.json) records their original paths and hashes.
No separate license file accompanied this material. Its README describes a private
submodule; that statement is historical provenance, not a new distribution license
or an instruction to reconnect it. The supplied `.git` pointer is preserved as inert
`.git.source`. Integration into lemonade does not assign MIT terms to the import.
The maintained English code contract and adaptable baseline acknowledge this source;
its logos and original agent metadata are not used as lemonade branding.
