- 소개의 중복 영문 머리말, 민트 점·큰 원·도형 패널, 제목 옆 장식,
  사진 주소 캡션과 불필요한 목록 태그를 제거했습니다. 사진 alt·본문·CI 안내 링크는 유지했습니다.
- 구·신버전 toast는 공유 CSS의 9999px capsule이며 상태 알림과 자동 닫힘을 보존합니다.
  검색·메뉴 모달은 모바일에서도 24px 모서리를 유지합니다.
- `node v2/tests/design-consistency.cjs`: 소개 2경로, 양 버전의 desktop/mobile
  실제 관심 삭제 알림, 검색·메뉴 모달의 24px·Escape·초점 복귀를 통과했습니다.
- Node 전체 13개와 readability 검사를 통과했습니다. 132개 경로 × 1440/390/320px에서
  렌더 실패·문서 넘침·JS 오류·HTTP 오류가 없었습니다.
- 상세 요청·개선·실패 이력과 재사용 기준은 단일
  [sejongpac-renewmakes](../../skills/sejongpac-renewmakes/SKILL.md)에 보존합니다.
  그 패키지의 실제 캡처와 구조·제품 계약 점검 17개도 확인했습니다.

## 시각 검토

- 1440/768/390/320px 홈 캡처와 프로그램 목록·달력·상세, 기관·이용안내·로그인 및 예매 상태를 확인했습니다.
- 큰 제목과 여백, 작품 포스터·일정의 정렬, 실용 링크를 구분했습니다. 이미지의 실제 비율을 보존하고 포스터 내부 글자가 잘리지 않도록 contain 처리합니다.
- 천 `#54c8e8`, 지 `#c36d15`, 인 `#ffe800`은 `--color-cheon`, `--color-ji`, `--color-in`으로 관리합니다. 밝은 색 위에 검정 본문을 사용합니다.
- 주요 캡처: `screens/hero-desktop.png`, `screens/home-{width}.png`, `screens/hero-390-section.png`, `programs/detail-390-top.png`, `flows/login-fixed-390.png`.
- 작은 보조 글씨를 13px로 보강했습니다. 이미지 속 포스터 글자는 원본 이미지의 일부입니다.
- 글자 확대 시 히어로가 내용에 맞춰 늘어나도록 최소 높이를 사용했습니다. 모바일 푸터 하단은 맨 위로 버튼과 문구가 겹치지 않도록 여백을 확보했습니다.

## 스킬 및 표준 검사

- `lemonade/scripts/lint.mjs --profile reference`: 최종 FAIL 0. 244개의 WARN은 기존 호환 스타일을 포함한 구분선·작품 분류·작은 영문 라벨 등입니다. 정보 비교를 위한 선, 기관·시즌 이름, 지정된 브랜드 컬러는 의도대로 사용합니다.
- `lemonade/scripts/inspect.mjs`: 처음 발견한 13px 미만 텍스트를 수정한 뒤 1440/768/390px에서 FAIL 0. 초기·수정 보고서는 `skill-inspect/`, `skill-inspect-refined/`에 각각 보존합니다. 동영상·많은 모션을 추가하라는 스타일 경고는 본 과제의 필수 조건으로 삼지 않았습니다.
- HTML-validate 11.16.2 standard+a11y: 진입 HTML 문제 0. 최초 전체 렌더 검사에서 공통 ARIA 명명·중복 landmark·버튼 type 등을 발견했습니다. 공통 템플릿 수정 후 좌석 선택·예매 확인을 포함한 대표 10상태를 다시 검사해 문제 0. 수정 전 전체 보고서와 수정 후 범위는 각각 `html-conformance-report.json`, `flows/html-conformance-fixed.json`입니다.
- CSSTree 4.0.1: 신버전 전체 CSS와 선택 화면 CSS의 파싱·속성값 오류 0. 이 도구의 CSS selector 의미 검증은 지원 범위 밖입니다.
- 모든 신버전 JS 문법 검사와 `git diff --check` 통과.

신규 작성 코드는 four-space 들여쓰기와 kebab-case 클래스명을 사용합니다. `styles/compat/`의 기존 CSS와 기존 기능에 종속된 DOM 클래스는 호환성을 위해 보존했습니다. 스킬 폴더는 배포 시 런타임 의존성이 아닙니다.

## 남은 경계

프로그램·가격·일정은 예시 데이터이고 실제 인증·결제·발권·기관 접수는 없습니다. 자료의 생성 이미지와 공식 사진 출처는 루트 README 및 `assets/images/README.txt`에 구분되어 있습니다. 실제 모바일 기기의 가상 키보드·스크린리더와 브라우저 UI의 400% 줌은 이번 자동화 환경에서 확인하지 않았습니다. 좁은 화면 재배치와 글자 확대 시뮬레이션은 이를 대체하는 인증이 아닙니다. 외부 영상·외부 기관 서비스의 가용성도 보증하지 않습니다.
