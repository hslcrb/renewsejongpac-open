# PPTX 요구사항 분석과 v3 대비 적용 범위

분석일: 2026-10-16. 원본: `.codex/assets/세종문화회관_분석-www.sejongpac.or.kr-한봄고등학교-이호세.pptx` (62슬라이드).

## 핵심 결론

PPTX는 콘텐츠 삭제보다 사용자 목적에 맞는 구조와 다음 행동을 강조한다. 일반 관람객과 대관 담당자에게 서로 다른 진입·진행 경로를 제공하고, 공통 정보는 어느 경로에서도 접근하게 한다. v3의 GNB와 상세 경로는 주요 IA를 이미 포괄한다. 따라서 v4의 우선 과제는 메뉴 수 확대보다 홈 Quick 예매 복원, 프로그램 탐색 범위 확장, 상세 화면의 콘텐츠 깊이와 다음 단계 연결 강화다.

## 추출·확인 범위

- `kordoc.cmd` 4.22.0으로 본문을 추출했다. CLI가 확장자를 `hwpx`로 표시했지만 변환은 성공했고, 출력은 56,745바이트였다. CLI의 형식 표시를 근거로 PPTX를 HWPX로 판단하지 않았다.
- PPTX ZIP 내부 62개 슬라이드 XML의 텍스트·표·이미지 연결을 별도로 확인했다. `slides.json`, `slides-text.md`, `slide-index.md`가 해당 산출물이다.
- 43쪽의 사용자 여정과 44쪽 IA는 텍스트가 아니라 SVG의 윤곽선으로 저장되어 있었다. `image36.svg`, `image37.svg`를 원본 비율로 렌더링하고 전체 및 4분할 이미지를 육안 확인했다.
- 49쪽 시안 이미지 `image38.png`, `image39.png`를 육안 확인했다. 해당 이미지는 서로 다른 디자인 실험을 포함하며 명시적 텍스트 요구와 일부 충돌한다.
- 원본 PPTX를 편집하거나 PowerPoint로 열지는 않았다. v3는 코드 수준에서 비교했다. 런타임 동작과 시각 품질 검증은 별도 작업이다.

## 사용자와 여정

자료는 이름·나이·직업 등을 붙인 정식 페르소나를 제시하지 않는다. 6–7쪽의 역할 기반 이용자 유형과 43쪽 여정을 근거로 구분해야 한다.

| 이용자 | 시작 목적 | 진행 경로 | 중요한 구분 |

| 개인·소규모 관람객 | 볼 프로그램 결정 또는 이미 정한 일정 예매 | 홈/목록·달력 → 상세정보 → 예매 → 이용안내 | 탐색 중인 사람과 바로 예매하려는 사람의 홈 진입을 구분 |
| 단체관람 담당자 | 학교·기업·기관을 대신해 프로그램 문의·신청 | 프로그램 확인 → 단체관람 안내 → 담당자·인원 정보 → 신청 | 신청자와 실제 관람자가 다를 수 있음 |

## 홈 6개 섹션의 구체적 동작

1. **이번달의 문화예술**: 한 번에 대표 프로그램 하나를 강조. 대표 이미지·이름·기간·장소·소개·상세/예매 CTA. 관람객과 단체·대관 이용자의 다음 행동을 구분한다.
2. **Quick 예매**: 좌측 미니 달력, 오늘 표시, 프로그램이 있는 날짜 표시. 우측에는 선택 날짜의 포스터·시간·장소와 예매 연결. 날짜 미리보기와 전체 프로그램 링크. 이미 관람 의향이 있는 사용자의 빠른 행동이 목적이다.
3. **프로그램 탐색**: 전체·공연·전시·교육·기획/시즌 탭. 오늘 콘텐츠 우선. 비교 가능한 카드 목록. 교육은 이 탐색 안에 통합한다.
4. **이용 안내**: 공간·교통·주차·편의시설·접근성·관람 유의사항·고객지원으로 연결. F&B는 이용정보 아래에 둔다.
5. **소식과 참여**: 공지·티켓오픈·대관공고와 이벤트·뉴스레터·멤버십·후원 진입을 성격에 맞게 묶는다. 모든 세부 항목을 동일 크기로 나열하지 않는다.
6. **세종문화회관**: 기관 서사와 정체성을 간결하게 전달하고 기관소개·예술단·ESG·정보공개·협력으로 진입. 단순 장식용 마감 섹션이 아니다.

구체적인 실제 요금·운영시간·기관 성과·캐스팅을 PPTX 시안의 예시에서 사실로 가져오면 안 된다. v3는 예시 데이터와 체험 경계를 표시하고 있다. v4 확장도 이 경계를 유지하거나 별도 검증된 공식 자료를 사용해야 한다.

## 충돌과 적용 우선순위

- 46·51·54쪽에는 현재시각·Liquid Glass·WebGL·커스텀 커서가 아이디어로 들어 있다. 저장소의 현재 v3 디자인 결정은 이러한 연출 일부를 후속 사용자 피드백으로 제거했다. PPTX의 과거 연출 제안만으로 최신 확정 디자인을 되돌리는 것은 요구사항 해석상 부적절하다.
- 49쪽 첫 시안은 파스텔 UI와 단일 프로그램, 두 번째 시안은 노란 포인트와 3분할 히어로를 보여준다. 두 번째 시안의 3분할은 46쪽의 ‘한 화면에 콘텐츠 하나’와 충돌한다. 화면 구조·정보 역할을 참고하고 시각 스타일·예시 정보는 그대로 복제하지 않는다.
- 49쪽 시안 중 후원이 ‘소식과 참여’ 메뉴 아래에 놓인 안도 있지만 44·48쪽 명시 IA는 ‘세종문화회관 > 후원’이다. 홈 소식에서 후원으로 연결할 수 있으며 주 경로는 명시 IA를 따른다.
- PPTX는 전용 로그인·마이페이지·결제 구현 세부를 명시하지 않는다. 해당 기능은 기존 v3의 완결된 체험 흐름을 유지하는 범위로 취급한다.
- 와이어프레임은 62쪽의 Figma 링크에 별도 존재한다. 이 보고서의 시각 확인은 PPTX에 포함된 시안만 다루며, 연결된 Figma 원본 검토와 구분한다.

## 검수 시나리오

1. 홈에서 날짜를 골라 해당일 공연·전시·교육 정보와 올바른 상세/예매·신청에 도달한다.
2. 기획·시즌 탭에서 해당 프로그램만 확인하고 빈 목록도 설명한다.
3. 오늘 진행중인 프로그램이 있을 때 홈 탐색에서 우선 확인한다.
4. 대관 이용자는 개요→시설→일정→절차→신청으로 이동하고 모든 단계에서 문의를 찾는다.
5. 시설의 대관용 정보와 관람용 정보가 서로 다른 목적에 맞게 나타난다.
6. 뉴스·이벤트·뉴스레터·멤버십·후원에서 다음 행동과 관련 상세 경로를 찾는다.
7. 기관 소개·역사·예술단·ESG·공개정보를 서로 연결하며 유용한 정보 없이 끝나는 화면을 줄인다.
