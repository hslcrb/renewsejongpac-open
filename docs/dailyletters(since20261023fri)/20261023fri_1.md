오늘은 세종문화회관 리뉴얼 웹사이트의 전체 페이지에 기본 화면과 내용을 갖추고 사이트의 미감과 세부 표현을 다듬었습니다. 기존 사이트와 기획서를 보며 공연 안내부터 방문 준비, 대관과 회원 서비스까지 이용 흐름을 연결했습니다. 기획서의 중심인 ‘사용하기 편한 사이트’를 기준으로 구성을 한 단계 발전시켰습니다.

글자의 크기와 강조 순서를 정돈하고, 메뉴와 로그인 영역의 높이를 맞춰 읽기 편한 화면을 만들었습니다. 버튼에는 부드러운 곡률과 옅은 테두리를 적용하고, 화면 크기에 따라 요소가 자연스럽게 배치되도록 조정했습니다. 작은 차이가 모여 통일감과 완성도를 높인다는 점을 체감했습니다.

퀵메뉴는 노랑과 초록이 원 안에서 부드럽게 일렁이는 모습으로 발전시켰습니다. 마우스 움직임과 원을 돌리는 방향에 반응하도록 만들고, 휴대전화와 키보드에서도 편하게 이용할 수 있도록 살폈습니다. 버튼과 안내창은 공통 부품인 컴포넌트로 정리해 여러 화면에서 같은 규격을 사용하도록 했습니다.

프로젝트 안내 문서인 README도 선생님과 동료가 쉽게 이해할 수 있도록 개편했습니다. 화면과 저장 공간의 연결을 그림과 설명으로 풀고, 눌러 흐름을 보는 자료를 만들었습니다. 여러 사람과 AI가 함께 개발할 때는 브랜치라는 작업 갈래를 나누고, 검토한 내용을 합치는 협업 기준도 정리했습니다.

세종문화회관 공식 홈페이지에서 로고 자산을 확보했으며 오늘 안으로 프로젝트에 반입할 예정입니다. AI가 웹페이지를 잘 만들도록 돕는 작업 지침 모음인 ‘림스플렉스(limsflex)’도 조만간 공개를 검토하고 있습니다. 화면의 구조를 적는 코드인 마크업을 체계적으로 정리하고, 결과물의 코드까지 읽기 좋고 아름답게 다듬는 데 활용하고자 합니다.

오늘은 사람의 감각과 판단이 디자인에 더하는 가치를 배웠습니다. 색의 인상과 글자의 간격, 움직임의 속도를 직접 살피고 고르는 과정에 사람의 소울(SOUL)이 담긴다고 느꼈습니다. AI의 제안에 사람의 검토와 보정을 더하는 HITL을 실천하며, 기능과 아름다움이 어우러지는 사이트로 발전시켜 나가겠습니다.
