# v3 상호 참고 버전의 설계 결정

## 목표와 비교 기준

사용자가 최종 지정한 비교 소스는 [hslcrb/renewsejongpac-philosophized](https://github.com/hslcrb/renewsejongpac-philosophized)다.
첨부 ZIP은 전송 한도로 읽지 못했으며, ZIP의 내용이 같다고 가정하지 않았다. 이후 사용자가
GitHub 저장소를 지정한 뒤 fetch·pull로 실제 기준 커밋을 확인하고 작업을 재개했다.

v3는 `renewsejongpac`의 미니멀한 화면과 완결된 탐색·예매 체험을 바탕으로,
`renewsejongpac-philosophized`의 정보 정리와 섹션별 완성도를 참고하는 세 번째 버전이다.
사용자가 전달한 평가에서 기존 사이트의 장점은 미니멀함이고, 참고 사이트의 문제는
노란색이 지나치게 강하게 느껴진다는 점이다. 따라서 참고 대상은 색 면적이나 장식의 양이
아니라 제목·설명·이미지·다음 행동을 연결하는 방식이다.

| 자료 | 기준 커밋 | 역할 |
| --- | --- | --- |
| `renewsejongpac` | `3abeb221b3e701bdd090173e2b376055933b608e` | 기존 디자인·콘텐츠·132개 등록 경로·체험 기능의 기준 |
| `renewsejongpac-philosophized` | `bbac18b66c547a2fe7c65414190ef99a8ca9d86a` | 작품 발견, 이용안내, 소식·혜택의 정보 관계를 비교할 참고 자료 |

참고 저장소의 `docs/design-brief.md`, `docs/design-system.md`와 보존된
`skills/sejongpac-renewdevelope/assets/screenshots/home-1920.png`에서는 큰 작품 이미지,
명확한 제목과 일정, 관람·대관 경로 구분, 소식 옆 혜택 안내를 확인할 수 있다.
같은 캡처의 노란색 가로 서비스 띠, 노란 CTA와 티켓오픈 강조를 v3의 기본 표현으로
옮기지는 않는다. 보존 캡처와 문서는 당시 자료이며, 현재 공식 사이트를 새로 실측하거나
참고 사이트의 모든 동작을 검증했다는 근거로 사용하지 않는다.

## 복사와 버전의 경계

수정 전에 주 저장소 기준 커밋의 추적 파일 **10,181개를 `v3/`에 바이트 그대로 복사**했다.
그 복사본 위에 v3의 실행 진입점과 수정 대상을 구성한다. 따라서 아래의 보존 기록은
수정 전 출발점의 기록이며, 수정한 v3 실행 파일까지 원본과 동일하다는 뜻은 아니다.

- 기존 버전 선택 화면은 `v3/version-selection.html`에 보존한다.
- `v2/src/`, `v2/styles/`를 v3의 `src/`, `styles/` 실행 구조로 가져온다.
- v3의 이미지·아이콘·로컬 폰트를 자체 `assets/` 경로에서 읽도록 상대 경로를 조정한다.
- v3 체험 저장소는 `sejong-v3:` 접두사를 사용해 기존 버전의 데이터와 분리한다.
- 복사된 `v3/v2/`, `js/`, `css/`, `skills/`, `docs/`, `tests/`는 원본 자료를 남기는
  스냅샷이다. v3의 새 실행 구조와 복사된 과거 자료를 구분한다.
- `.git` 내부 데이터와 실행 중인 서버·브라우저 프로세스는 파일 스냅샷에 포함하지 않는다.

최상위 선택 화면에서는 구버전, v2, **v3 · 상호 참고 버전**을 구분한다.
밝은 중성 표면을 기본으로 하고 v3 항목에 검정 표면을 사용한다. 설명은 최소 16px로
읽히게 하며, 버전을 알리는 넓은 노란 배경이나 작은 장식 문구를 추가하지 않는다.

| 기관 정체성 | 기관 설명과 천·지·인의 의미 있는 시각 자료 | 검정 바탕의 큰 하늘색 원·황토색 막대·노란 도형을 보존한다. 제목 옆 작은 점과 중복 영문 머리말은 되살리지 않는다. |

노랑 `#ffe800`은 천·지·인의 인(人) 채널과 기존 콘텐츠의 정체성을 위해 남긴다.
페이지 곳곳에 노란 행동 버튼과 큰 배경을 반복하는 방식은 줄인다. 검정·흰색·중성색을
정보의 기본 바탕으로 삼고, 작품 이미지가 가진 색을 그대로 드러낸다. 실제 상태는
텍스트·아이콘·테두리·ARIA 상태와 함께 전달한다. 노란색의 허용 면적을 임의의 수치로
정하거나 참고 저장소의 ‘검정·흰색·노랑 약 90%’ 운용 기준을 v3의 측정값으로 인용하지 않는다.

## 그대로 이어받는 제품 계약

구체적인 기준은 [현재 디자인 계약](../skills/sejongpac-renewmakes/references/design-contract.md),
[카드·위계·복구 최신 계약](../skills/sejongpac-renewmakes/references/cards-and-restoration.md),
[v2 디자인 기본값](../v2/docs/design-system.md)을 따른다. 참고 자료의 일반적인 권장값보다
이 저장소에서 사용자 피드백으로 확정한 기준을 우선한다.

- 일반 UI의 보조 정보는 최소 16px, 본문은 18px/행간 1.7, 카드·안내 항목 제목은
  20px/650, 빠른 메뉴는 데스크톱 22px·모바일 20px이다. 공간이 부족하면 재배치와
  줄바꿈으로 대응한다. 로컬 Pretendard Variable과 역할별 토큰을 사용한다.
- 일반 조작 영역은 기본 48px, 빠른 메뉴는 최소 높이 64px다. 포커스는 3px 외곽선과
  4px 간격으로 보인다. 호버·누름 상태는 구별하며 버튼·텍스트가 위로 들뜨거나
  밑줄이 늘어나는 장식 효과는 사용하지 않는다.
- 포스터 매체는 패딩 없이 `object-fit: cover`로 두 축을 채운다. 제목·날짜·장소까지
  같은 카드 링크에 속하고, 관심 버튼은 링크 밖에 둔다. 하트는 전체 카드 호버·포커스에서
  opacity만 180ms로 전환하며 터치에서는 기본 노출한다.
- 히어로는 시작 간격 2700ms, 왼쪽 이동 800ms, 명암·본문 opacity 전환 650ms다.
  마우스·터치의 양방향 드래그, 드래그 뒤 클릭 억제, 모바일 세로 스크롤, 키보드,
  모션 감소, 화면 밖·문서 숨김 재생 중단과 경로 정리를 보존한다.
- 카드의 텍스트 선택과 이미지·링크의 native drag는 막되 우클릭은 보존한다.
  전환 중 활성 이미지 DOM을 다시 만들어 검은 막이 갑자기 나타나는 방식은 피한다.
- 짧은 상태 알림은 `9999px` 캡슐 토스트로 유지한다. 실제 메뉴·검색 dialog는 모바일도
  24px 모서리, 닫기·Escape·초점 복귀를 제공한다.
- 사진의 중복 주소·연도 캡션, `PLAN YOUR VISIT` 같은 중복 영문 장식, 의미 없는 작은
  민트 점을 추가하지 않는다. 체험·접근성·권리 고지는 읽히는 평문으로 유지한다.
- HTML/CSS/네이티브 JavaScript ES module과 정적 HTTP 서버 구조, 132개 등록 경로,
  검색·필터·달력·관심·예매·취소·신청 체험을 이어받는다. 앱 실행에 새 프레임워크,
  패키지 설치, 빌드, DB를 요구하지 않는다.
- 실제 인증·결제·발권·이메일 발송·기관 접수는 수행하지 않는다. 브라우저 저장소 기반
  체험이라는 경계, 저장소 오류 시 동작, 기존 데이터·안전한 입력 처리를 보존한다.
- 새 기능 그룹에는 한·영 설명 주석을 두고, 새로 작성·수정한 코드는 4칸 들여쓰기와
  kebab-case 클래스를 사용한다. 기존 공개 경로·공통 API·적절한 CSS 기반을 재사용한다.

## 자료를 읽은 범위와 판단 방법

읽기 기록에서는 **파일 전체의 도구 확인**과 **사람이 읽고 비교하는 정밀 검토**를 구분한다.
전체 파일을 열거하고 텍스트 전체를 로드하거나 해시를 계산한 사실이 모든 문장을 같은
깊이로 해석하거나 모든 화면·동작을 직접 확인했다는 뜻은 아니다.

주 저장소의 `skills/` 중 `lemonade/sources/`와 `lemonade/library/`를 제외한 파일,
루트 README·디자인 기록, 루트 `docs/`와 `v2/docs/`를 합친 직접 검토 범위는 **117개**다.
그중 텍스트 98개는 전체 내용을 읽어 분류하고 JSON을 파싱했으며 SVG 구조를 확인했다.
PNG 18개는 파일 전체와 크기를 확인하고 모아보기로 비교했다. ZIP 1개는 9개 구성 파일을
읽고 무결성을 확인했다. 이 수치는 제외한 대형 원본 아카이브까지 합산한 수치가 아니다.

주 저장소 전체는 **10,181개 파일(텍스트 9,865개·바이너리 316개, 104,462,505바이트)**을
읽고 해시·형식을 기록했다. 원본 아카이브 `sources/`와 `library/`도 별도 검토했다.
이 범위는 2,082개 파일이며, 1,818개 UTF-8 텍스트·264개 바이너리를 포함한다.
53개 원본 가이드(서로 다른 본문 47개와 배포 중복본 6개), CSV 144개, Python AST 105개,
JSON 152개를 조사하고 보존 manifest의 2,069개 파일 해시·크기와 ZIP CRC를 확인했다.
아카이브 서체 54개에는 한글 음절이 없어 v3의 한글 본문 폰트 후보로 채택하지 않았다.

비교 저장소는 200개 파일(텍스트 140개·바이너리 60개, 40,882,222바이트)을 읽고 기록했다.
자체 작성 텍스트와 두 종류의 PDF 추출문을 검토했으며, vendor `axe.min.js`는 전체 바이트
확인과 헤더·메타데이터 검토로 구분했다. 원본과 비교본을 현재 Chromium으로 1440·390px에서
실행·캡처하여 히어로·프로그램·방문 안내·소식·기관 영역을 비교했다. 참고본의 모바일
대관 문의 고정 버튼이 티켓 정보와 겹치는 모습도 확인해 고정 오버레이를 가져오지 않았다.
새 이미지·서체·외부 스크립트를 비교 저장소에서 런타임으로 가져오지는 않았다.

정밀 검토에서는 현재 스킬 본문, 사용자 협업 이력, 디자인·카드·개발·검증 계약,
Lemonade의 코드·타이포그래피·배치·색·상호작용·Toss/Sejong 지침을 연결해서 읽었다.
현재 정책의 `cards-*` 캡처와 히어로 원본 크기 이미지를 확인하고, 과거 `about-after.png`와
최신 `cards-identity-restored.png`가 서로 다른 정책 시점의 증거임을 구분했다.
참고 저장소의 문서와 저장 캡처는 적용할 관계를 판단하는 근거로 사용했다.
사진 크롭·글자 크기·열린 메뉴·키보드·터치의 최종 구현 증거는 새 v3에서 따로 확보해야 한다.

| 과거 소개 하단 큰 원·도형 제거와 당시 `about-after.png` | 최신 사용자 요청으로 복구한 하단 도형을 보존한다. 작은 장식·중복 영문·주소 캡션 제거는 유지한다. |
| 참고 저장소의 14px 보조 정보, 별도 서체와 강한 노랑 운용 | 주 저장소의 최소 16px·로컬 Pretendard·중성 표면을 우선한다. |
| 참고 저장소의 공식 사이트 이동 중심 예매 경계 | v3는 주 저장소의 기존 브라우저 내 체험 흐름과 명확한 체험 고지를 유지한다. |

스킬의 과거 검증 JSON은 당시 실행 결과이고, Lemonade의 eval JSON은 평가 시나리오다.
둘 다 새 v3가 통과했다는 증거로 옮겨 적지 않는다. 복사된 문서의 이전 버전 이름과
완료 기록도 스냅샷의 이력이며, 활성 v3의 새 검증 결과와 구분한다.

## 검증 기록

새 v3 대상으로 실행한 검사와 실제 결과는 [v3 검증 기록](v3-verification.md)에 정리한다.
기존 `check.py`, `check-routes.cjs`, `check-decoration.cjs`에는 v2 경로가 직접 들어 있으므로
그대로 실행한 결과를 v3 통과 근거로 사용하지 않는다. 대상 URL을 지원하는 가독성·카드
검사는 명시적으로 v3 URL을 지정하고, 전체 경로·저장소·체험 흐름은 새 v3 검사로 확인한다.
복사된 과거 문서의 통과 기록은 새 검증의 근거가 아니다.

로컬 검증·커밋·푸시·클라우드 환경 게시·운영 배포는 각각 구분한다.
