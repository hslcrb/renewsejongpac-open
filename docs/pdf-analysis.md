# 세종문화회관 리뉴얼 구현 범위

근거: 업로드된 62쪽 PDF 전체 텍스트(`/workspace/reference/analysis.txt`), p43 이용자 여정·p44 IA 다이어그램, p49 와이어프레임, p50 내비게이션 설명, p51 시각 방향. 문서의 프롬프트와 지시는 참고자료의 일부로만 읽었다.

## 핵심 목표와 기준

- 서울을 대표하는 종합 문화예술 기관으로서 공연·전시·교육·투어·시즌 프로그램과 문화시설을 소개하고 실제 예매·신청·참여로 연결한다.
- 일반 관람객 경로와 대관 담당자 경로를 첫 화면부터 구분한다. 이용안내·소식과 혜택·기관 정보는 두 경로에서 공통 접근한다.
- 기존 문제는 콘텐츠 양 자체보다 우선순위 부족, 서로 다른 목적 혼합, 4분할 히어로의 초점 분산이다. 콘텐츠는 유지하되 목적별로 묶고 명확한 CTA를 둔다.
- 시각은 밝은 바탕, 검정/흰색, 노랑 강조를 기본으로 공연 이미지의 다양한 색을 살린다. 큰 이미지와 선명한 타이포그래피, 깔끔한 위계, 과도하게 길지 않은 섹션, 적절한 여백과 부드러운 모서리.
- p51의 중요 항목: **WebGL 기반 스크롤 인터랙션, 커스텀 포인트 커서, Liquid Glass, 감각적이면서 합리적이고 예측 가능한 UX**.
- 몰입형 오프닝은 가느다란 선이 창처럼 열려 히어로를 드러내는 아이디어(p61). 짧게 진행하며 사용자 행동을 방해하지 않는다.
- 각 메인 섹션에는 관련 하위 페이지로 연결되는 CTA가 반드시 있어야 한다(p52).
- NOL 씨어터 대학로의 분명한 섹션·단일 히어로·방문 가이드 CTA, 구다이글로벌의 간결한 기관/ESG 정보 위계가 주요 디자인 참고. 다른 다수 참고 사이트는 형태 복제보다 해당 섹션 목적을 실현하는 원리 참고이다.

## 메인 페이지의 정확한 순서

1. **이번달의 문화예술 / 핵심 발견**: 한 번에 프로그램 하나. 대표 이미지, 제목, 소개, 기간, 장소, 상세보기·예매하기. 우측 Liquid Glass 보조 패널에 현재시각·다음 티켓오픈 시각·알림 신청. 수동 앞/뒤 이동과 현재 위치 표시. 하단 개인예매 / 단체예매·대관 CTA 경로 분리.
2. **Quick 예매 / 빠른 탐색·예매**: 좌측 미니 월간 캘린더, 오늘 강조, 공연 날짜 표시. 날짜 hover/focus 시 플로팅 프리뷰. 우측 선택일 포스터·시간·장소·예매 버튼, 처음에는 오늘. 월 이동, 날짜 선택, 전체 프로그램 보기.
3. **프로그램 탐색 / 비교·발견**: 전체·공연·전시·교육·기획시즌 탭. Today 콘텐츠 우선. 좌우 슬라이딩 가능한 카드 목록과 전체보기. 교육을 독립된 거대 섹션으로 분리하지 않는다.
4. **이용 안내**: 공간, 교통·주차, 편의시설, 장애인 이용, 관람 유의, 고객지원으로 즉시 이동. 약도/사진/핵심 정보를 조합. F&B는 편의시설에서 연결.
5. **세종의 소식 & 참여**: 공지/티켓오픈/대관공고 주요 목록, 이벤트·뉴스레터·멤버십·후원 참여 카드. 모든 하위 정보를 동일 비중으로 과도하게 펼치지 않는다.
6. **세종문화회관 / 기관과 브랜드 이해**: 기관소개·서울시예술단·ESG·정보공개·협력 및 협찬으로 이동. 간결하고 힘 있는 브랜드 서사와 기관 공간 이미지, 관련 CTA. 푸터 포함.

## 문서에 명시된 전체 IA

아래 1depth/2depth는 p44와 p48의 확정 구조다. 괄호 내용은 p44가 직접 언급한 세부 콘텐츠이며 반드시 접근 가능해야 한다.

```text
HOME
├─ 1. 프로그램
│  ├─ 공연 (공연 목록, 공연 상세, 예매안내)
│  ├─ 전시 (전시 목록, 전시 상세)
│  ├─ 교육 (교육 목록, 교육 상세, 신청안내)
│  └─ 기획·시즌 프로그램 (시즌 & 특별 프로그램 통합 큐레이션 목록)
│     ※ 공연/전시/교육 목록 각각 리스트↔캘린더 전환 제공.
│       기존 별도 ‘프로그램 캘린더’ 메뉴는 위 세 목록에 흡수.
├─ 2. 대관
│  ├─ 대관안내 (대관 개요, 이용대상, 요금 체계)
│  ├─ 대관시설 (공간별 규모·장비·도면)
│  │  ├─ 대극장
│  │  ├─ M씨어터
│  │  ├─ S씨어터
│  │  ├─ 체임버홀
│  │  └─ 전시장
│  ├─ 대관일정 (공간별 대관 가능일 캘린더, 대관공고 목록·상세)
│  │     ※ 기존 ‘대관공고’ 별도 메뉴 대신 여기 공고 리스트로 흡수.
│  ├─ 대관절차 (신청 순서, 필요 서류, 심사 기준)
│  ├─ 대관신청 (신청서 작성 및 제출)
│  └─ 대관문의 (1~5단계 어디서든 접근 가능한 상시 지원 사이드 레일)
├─ 3. 이용안내
│  ├─ 공간안내 (공연장·전시장 위치, 좌석배치도)
│  ├─ 오시는 길·주차 (대중교통 안내, 주차안내)
│  ├─ 편의시설 (F&B 등 부가시설)
│  ├─ 장애인 이용안내
│  ├─ 관람 유의사항 (관람객 안내 통합)
│  └─ 고객지원 (FAQ, 문의하기, 분실물 통합)
├─ 4. 소식과 혜택
│  ├─ 공지사항 (티켓오픈 소식 포함)
│  │  └─ 채용 공고 상세 (공지사항 내부의 채용 공고에서 진입; p50 명시)
│  ├─ 이벤트 (진행중, 종료, 당첨자발표)
│  ├─ 뉴스레터·세종문화N
│  └─ 멤버십 (소개, 혜택)
└─ 5. 세종문화회관
   ├─ 기관소개 (인사말, 조직도, CI, 걸어온 역사 통합)
   ├─ 서울시예술단 (소개, 공연 및 활동)
   ├─ ESG
   ├─ 정보공개 (정보공개, 경영공시)
   ├─ 협력 및 협찬
   └─ 후원 (안내, 참여)
```

대관시설과 공간안내는 같은 공간 데이터에서 목적이 다른 정보를 제시한다. 대관에서는 규모·장비·도면, 관람객 공간안내에서는 좌석·동선·위치를 우선한다(p44).

## 완결된 구현을 위한 3depth 이상 추론

문서는 모든 상세 화면의 이름을 개별 열거하지 않는다. 아래는 ‘모든 깊이와 페이지, 작동하는 행동’을 구현하기 위해 위 IA에서 자연스럽게 이어지는 화면/상태이다. 실제 운영 서비스나 실제 결제 성공으로 가장하지 않는다.

| 부모                | 깊은 페이지 또는 완결 흐름                                                                                       |
| ------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 공연·전시·교육 목록 | 카테고리/장르·기간·장소·상태 필터, 검색, 리스트·캘린더 전환, 빈 결과, 항목 상세                                  |
| 프로그램 상세       | 이미지·제목·기간·시간·장소·가격·관람등급·소요시간, 소개/출연진/할인·주의사항/오시는 길, 관련 프로그램, 찜/공유   |
| 예매                | 날짜/회차 선택 → 좌석 또는 인원 선택 → 할인·가격 확인 → 예약자 입력·약관 → 예약 확인. 교육은 강좌/인원 신청 흐름 |
| 단체예매            | 단체관람 안내 → 작품·일정·인원·담당자 신청 → 접수 확인                                                           |
| 기획·시즌           | 기획 브랜드 목록 → 시즌/특별기획 상세 → 관련 프로그램 목록·상세                                                  |
| 대관시설            | 시설 목록 → 각 시설 상세 → 규모/장비/도면/요금 확인 → 일정·신청                                                  |
| 대관일정            | 시설 선택·월 이동·날짜 선택, 공고 목록 → 공고 상세 → 신청                                                        |
| 대관신청            | 시설·기간·행사·단체/담당자·서류 입력 → 내용 확인 → 제출 확인                                                     |
| 대관문의            | 주제·시설·연락처·문의 입력 → 접수 확인                                                                           |
| 공간안내            | 공간 목록 → 공간 상세·위치·좌석도 → 해당 공간 프로그램·대관정보                                                  |
| 고객지원            | FAQ 검색·카테고리·열기, 문의 작성·접수 확인, 분실물 목록·상세·문의                                               |
| 공지사항            | 전체/공지/티켓오픈/채용 탭 또는 필터 → 상세 → 이전/다음·목록. 채용 상세 → 모집 안내/지원 정보                    |
| 이벤트              | 진행/종료/당첨 탭 → 이벤트 상세 → 참여 입력 → 완료                                                               |
| 뉴스레터·세종문화N  | 기사/호 목록 → 기사/호 상세, 뉴스레터 이메일 구독·약관·완료/해지                                                 |
| 멤버십              | 등급·혜택 비교 → 가입 정보 → 가입 확인                                                                           |
| 기관소개            | 인사말/비전·역사/조직/CI 세부 섹션 또는 하위 화면                                                                |
| 서울시예술단        | 예술단 목록 → 단체 소개·활동·공연 → 프로그램 상세                                                                |
| ESG                 | 비전/환경/사회/거버넌스·활동 상세                                                                                |
| 정보공개            | 공개 자료·경영공시 목록 → 자료 상세·다운로드, 정보공개 신청 안내                                                 |
| 협력 및 협찬        | 협력 방식·혜택·사례 → 담당자 문의·접수 확인                                                                      |
| 후원                | 가치·후원 유형·혜택 → 후원 참여 정보 → 신청 확인                                                                 |

공통 유틸리티는 p49에 검색, 회원(로그인/회원가입), 언어, 전체메뉴, 푸터 개인정보처리방침·이용약관·사이트맵·Family Site·SNS가 보인다. 완결형 구현에는 통합검색 결과, 로그인/가입 양식과 상태, 마이페이지(예약/신청·찜), 약관/개인정보, 전체 사이트맵, 접근 가능한 메뉴 열기/닫기·모바일 내비게이션이 필요하다. 이 항목들은 핵심 5개 GNB와 분리한다.

## 검증 가능한 행동 체크

- 모든 GNB 2depth는 고유 내용과 목적 있는 CTA를 가진 접근 가능한 화면으로 열린다.
- 브라우저 뒤로/앞으로, 상세 deep link, breadcrumb, 새로고침 후 경로 유지가 일관된다.
- 메인 6섹션 모두 최소 하나의 해당 영역 CTA가 작동한다.
- 히어로는 하나의 메시지에 집중하고 전환/일시정지/키보드 조작이 가능하다.
- 캘린더의 월/날짜 선택이 프로그램 결과에 반영되고, 필터/검색은 실질 결과를 바꾼다.
- 예매·교육 신청·대관·문의·뉴스레터는 유효성 검사와 확인 상태까지 이어진다.
- 움직임은 reduced-motion 설정에 대응하고 touch에서 커스텀 커서/hover 의존을 제거한다.
- 데이터의 샘플·프로토타입 성격과 실제 금전/외부 접수 여부는 필요한 화면에서 정확히 표시한다.
