# v4 · 예술을 만나는 모든 여정

## 목표와 근거

사용자가 제공한 Figma IA·사용자 여정(268:1525), 홈 와이어프레임(299:1656), 메인 콘텐츠 설명(299:1657), 62장 분석 PPTX를 근거로 v3 전체를 복사한 독립 v4를 만든다. 원본은 `zfSYLSrl68L2yzff3rveZG` FigJam이며 읽기 도구로 구조와 렌더를 확인했다. PPTX는 `.codex/assets/세종문화회관_분석-www.sejongpac.or.kr-한봄고등학교-이호세.pptx`, kordoc 추출과 임베드 자료의 추가 검토를 사용한다. 원본 추출물은 `.codex/analysis-v4/`에 보존한다.

v3의 실제 구현은 138개 경로, 15개 프로그램, 5개 공간, 7개 예술단이다. 새 버전은 전체 사본으로 시작하고 기존 경로를 모두 제공한다. v3와 구버전의 제품 파일을 변경하지 않는다. 루트 버전 선택 화면에는 v4를 추가한다. 현재 프로젝트는 HTML/CSS/네이티브 ES module 기반의 정적 체험 사이트다.

## 정보구조와 사용자 여정

GNB는 프로그램 / 대관 / 이용안내 / 소식과 혜택 / 세종문화회관의 다섯 그룹을 유지한다. 로그인·가입·검색·전체 메뉴는 헤더에서 접근한다. 프로그램의 공연·전시·교육 목록에는 리스트/캘린더 전환을 유지한다. 별도 최상위 프로그램 캘린더 메뉴는 만들지 않는다.

관람객은 발견 → 상세 → 예매·신청 → 내역 → 방문 준비를 잇는다. 대관 이용자는 개요 → 시설 → 가능일 → 절차 → 신청을 잇고, 대관 문의는 모든 단계에서 접근한다. 이용안내·소식·기관 정보는 어느 여정에서든 GNB에서 접근한다.

추가 기능은 기존 데이터와 흐름에 연결한다.

- 홈 Quick 예매: 날짜, 프로그램, 회차, 인원 선택과 실제 예매/입장/교육 신청 목적지 연결. 선택값은 다음 단계까지 보존하고 해당 날짜에 일정이 없으면 명시한다.
- 프로그램 발견: 공연·전시·교육·기획/시즌을 구분하고 날짜와 시간, 장소, 예매 상태를 노출한다. 오늘 해당 프로그램과 가까운 일정을 정직하게 구분한다.
- 방문 계획: 프로그램·공간·이동수단·접근성 선택에 따라 시간표와 안내를 구성하고 공유 가능한 URL 또는 브라우저 저장으로 이어진다. 실시간 길찾기를 주장하지 않는다.
- 대관 공간 비교: 최대 세 공간을 정원·용도·장비·안내 조건으로 비교하고 선택 공간을 가능일/신청으로 전달한다. 임의의 요금·가능일을 실제 기관 확정 정보처럼 표기하지 않는다.
- 검색: 프로그램·공간·이용안내·소식·기관 콘텐츠를 구분해 검색하고 가까운 행동으로 연결한다. 빈 결과와 짧은 검색어, 한국어 공백, 키보드 제출을 처리한다.

## 홈 여섯 영역

1. 이번 달의 문화예술: 주요 공연의 큰 사진/포스터와 간결한 문구, 실제 링크, 이전·다음·일시정지와 드래그. 기존 2700ms 재생·800ms 이동 계약을 유지한다.
2. 빠른 예매: 읽기 쉬운 날짜/프로그램/회차/인원 입력, 상태와 다음 행동. 서울 기준 오늘 날짜를 사용한다.
3. 프로그램 탐색: 세로 포스터, 전체 카드 링크, 하단 관심 버튼, 공연·전시·교육·시즌 탭과 달력 전환.
4. 처음 방문하는 사람을 위한 안내: 공간·오시는 길·접근성·관람 예절을 실제 화면으로 연결. 기존 오른쪽 공통 미리보기의 부드러운 교체를 유지·발전시킨다.
5. 소식과 참여: 공지·티켓오픈·이벤트·뉴스레터·멤버십의 성격을 구분하며 관련 콘텐츠가 실제로 열린다.
6. 기관 브랜드: 소개·예술단·ESG·정보공개·협력·후원의 구체적 진입점. 천지인 아이덴티티는 보존한다.

원본의 Lorem ipsum, 타 브랜드 메뉴, 임시 연락처, 가상의 실적은 최종 화면에 옮기지 않는다. 명시된 콘텐츠 역할을 보존하면서 기존 간결함과 가독성을 발전시킨다.

## 시각과 모션

lemonade의 세종 프로필은 프로그램 비교와 포스터 중심 편집에, Toss 프로필은 소개의 여백·큰 단문·이미지 장면·설명과 행동의 연결에 적용한다. Toss와 GDWEB 선정 사례는 관찰/공식 설명/제안값을 구분해 기록한다. 타 사이트의 로고·사진·고유 문구를 복사하지 않는다.

공통 화면은 흰색과 옅은 중성 배경, 깊은 잉크색, 제한적인 천지인 강조색을 사용한다. 노랑을 화면 전체의 주색으로 확장하지 않는다. 제목·본문·메타의 위계를 명료하게 하고 기본 본문 18px, 보조 정보 최소 16px, 조작 영역 48px를 유지한다. 기존 지역별 CSS 위에 명확한 v4 공통 스타일 계층을 둔다.

소개는 `/about`와 `/about/introduction`에 적용한다. 전면 이미지와 큰 문장 → 시민의 예술 경험 → 공간과 예술단 → 연혁 → 천지인 → ESG·공개·협력·후원의 장면으로 이어진다. 콘텐츠/동작이 확인되지 않은 영상 재생 버튼은 만들지 않는다. 미디어 스크롤 확장과 장면 등장에는 정적 대체 상태가 있어야 한다.

기존 motion.js의 WAAPI·cleanup·reduced-motion 계약을 재사용한다. 카드나 버튼 hover-lift, 늘어나는 장식 밑줄은 금지한다. 입력은 즉시 반영하고 상태 변경에만 짧은 전환을 적용한다. 스크롤을 가로채지 않는다. 타이머·리스너·observer는 경로를 떠날 때 정리한다. 모션 감소 설정, 빠른 반복 입력, 키보드와 터치를 검증한다.

## 독립성과 완료 기준

- v3 전체 파일을 v4로 복사한 최초 기준 커밋과 바이트 검증 기록을 보존한다.
- v4의 실제 런타임 저장소는 `sejong-v4:`이며 v3 저장값을 읽거나 덮어쓰지 않는다. 역사 자료의 v2/v3 표기는 보존한다.
- 기능별 작은 Node 검사와 브라우저 시나리오를 먼저 실행한다. 마지막에 전체 관련 Node suite를 한 번 실행한다.
- 138개 기존 경로와 새 경로의 1440/390/320px 화면, 깨진 이미지·내부 링크·가로 넘침·콘솔 오류를 검사한다.
- 예매/입장/교육 신청, 대관 문의·신청, 계정/관심/내역, 이벤트/뉴스레터, 굿즈 기존 흐름과 새 탐색 흐름을 검증한다.
- 새 홈과 소개를 실제 렌더로 검토하고 모바일/키보드/모션 감소 상태를 남긴다. 지원 브라우저 도구 연결이 불가능하면 이를 해결하거나 미검증 상태로 명시하며 목표 완료로 처리하지 않는다.
- `codex/` 브랜치, 영어 접두사+한국어 커밋, `--no-ff` 통합을 사용한다. reset/강제 push는 사용하지 않는다. 원격 main 반영은 전체 검증 후 수행한다.
- 기존 루트 tests/v3.test.mjs의 132개 경로 동등성 검사는 과거 계약 오류다. 제품 변경과 구분해 기존 경로 보존과 신규 경로 허용으로 바로잡고 근거를 남긴다.
