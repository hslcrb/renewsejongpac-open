# 기관소개 — 오래된 멋, 새로운 움직임

## 목적과 범위
`/v5/about/introduction/`의 기존 네온·CSS 장식 화면을 한국의 선·색·몸짓을 담은 영상 중심 경험으로 교체한다. 별도 사이트를 만들지 않고 기존 Next.js 14 / React 18 프로젝트와 GNB·푸터를 유지한다. 기존 다른 버전은 보존한다.

## 아트디렉션
먹색, 따뜻한 한지색, 주홍을 중심으로 큰 한글 타이포그래피와 색동 띠를 사용한다. 장면 순서는 첫인상 → 한국의 결 → 세종의 역할 → 방문 행동이다. pear.no의 장별 탐색과 큰 여백을 참고하되 코드·시각 자산을 복제하지 않는다. Pinterest의 한글 포스터·색동 직물은 형태 연구용이며 사이트 자산으로 복사하지 않는다.

## 구현 계약
- 첫 화면 실사 영상 + 독창적인 SVG/CSS 색동 그래픽. 실제 촬영 장소와 세종문화회관을 혼동시키지 않는 출처 고지.
- 처음 헤더는 투명 유리 효과, 56px 이후 숨김. 키보드 포커스·열린 메뉴에서는 다시 노출.
- 푸터는 끝에서 420ms 등장, 위로 스크롤 시 140ms 퇴장. 키보드 포커스는 항상 노출.
- 장별 이동, 연속 진행선, 스크롤 연동 구성, 색동 인터랙션, 영상/모션 정지 버튼.
- 기본 본문 18px 이상, 보조 텍스트 16px 이상, 버튼 48px 이상.
- reduced-motion·data saver·비활성 탭·화면 밖 영상은 자동 재생하지 않음. 스크롤 가로채기 금지.
- 텍스트 선택의 배경만 전역 투명화하고 선택·복사 기능은 보존.
