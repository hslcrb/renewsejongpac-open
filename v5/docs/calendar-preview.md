# 관람 예약 달력 정비

2026-10-23. 서로 붙어 있던 타원형 날짜를 간격이 있는 날짜 조작으로 바꾸고, 날짜별 프로그램을 커서 옆에서 미리 볼 수 있게 했다.

- 날짜는 최대 48×48px, 공통 control 곡률 12px를 사용한다. 기본 상태의 경계는 없고 선택한 날만 오프블랙으로 채운다. 오늘 표식과 일정 점은 유지한다.
- `BookingCalendar`가 `BookingDatePreview`를 소유한다. 미리보기는 등록된 `SystemSurface` elevated 표면과 공통 텍스트·컬러 토큰을 조합한다. 제품과 가이드가 같은 구현을 사용한다.
- 마우스를 올린 날짜의 이름·프로그램 수·최대 세 프로그램의 이미지·제목·장소를 표시한다. 추가 프로그램 수를 안내하며, 클릭해야 실제 예약 날짜가 바뀐다. 검증되지 않은 회차·가격은 새로 만들지 않는다.
- 위치는 프레임당 한 번 갱신하고, 화면 경계에서 방향을 바꾼다. 크기 변화는 ResizeObserver로 다시 측정한다. 미리보기 안으로 커서를 옮겨도 유지되며, 떠나면 160ms 뒤 닫힌다.
- 키보드 초점에서도 미리보기를 제공한다. Escape는 초점을 옮기지 않고 닫는다. 날짜 확정·월 변경·페이지 스크롤·화면 크기 변경 시에도 닫힌다.
- 430px 이하에서는 공통 `SystemField`의 네이티브 날짜 입력을 사용한다. 날짜 변경과 비우기를 지원하며, 터치로 날짜를 고를 때 hover에 의존하지 않는다.
- 일반 환경의 진입은 140ms fade이고 모션 감소 환경에서는 생략한다. 좌표·visibility를 암묵적으로 전환하지 않아 첫 표시의 빈 본문과 커서 추적 지연을 방지한다.

현재 등록 구현은 **50개**, 제품 연결 47개·가이드 전용 3개·미사용 0개다. 미리보기는 달력의 내부 지원으로 등록하며 별도 가짜 가이드 예제를 만들지 않는다.
