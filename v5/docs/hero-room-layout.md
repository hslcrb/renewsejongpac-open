# 히어로와 개인 공간 개선

사용자가 첨부한 두 히어로 화면을 기준으로 현재 카드와 티켓오픈·유리 시계를 유지하며 양옆 작품을 드러냈다. 새로운 페이지 스킨 대신 등록된 컴포넌트와 토큰을 수정하고 조합했다.

## 컴포넌트 연결

- `HeroCarousel` → `HeroSlide` + `HeroCompanion` + `SystemButton` + `SystemIconButton`. 양옆 작품명으로 이동하고, 수동 전환은 스크린리더에 알린다. 기존 홈 앵커도 유지한다.
- `SystemButton`의 `inverse-quiet`는 사진 위에서 읽히는 흰색 조작 베리언트다. 제품과 디자인 가이드의 버튼 예제가 같은 구현을 사용한다.
- 이전·중앙·다음 카드와 이동용 양끝 버퍼를 유지해 마지막 작품에서도 연속 이동한다. 가로 드래그만 포인터를 캡처하고 세로 스크롤은 브라우저에 맡긴다. 캡처 전 카드 밖에서 포인터를 놓아도 정리한다.
- 자동 재생은 호버·초점·화면 이탈·문서 숨김·열린 퀵메뉴에서 멈춘다. 재생 버튼을 명시적으로 누르면 기존 초점 정지를 해제한다. 이후 새 초점 진입은 다시 멈춘다. 모션 감소 설정에서는 자동 재생을 끄고 수동 이동을 즉시 처리한다.
- 좁은 화면에서는 양옆 카드의 작은 조각을 유지하고, 읽을 수 있는 두 작품명 버튼을 카드 바로 아래에 배치한다.

등록 현황은 44개, 제품 연결 42개, 문서 전용 2개, 미사용 0개다. `HeroCarousel`은 실제 홈 경로로 미리 보고 `HeroSlide`는 독립 예제로 확인한다.

## 넓이와 내용에 따른 배치

`design-tokens.ts`의 공통 프레임은 최대 108rem(1728px), 여백은 20–48px다. 히어로 중앙 카드는 최대 90rem(1440px)이며 양옆 노출 폭과 간격도 토큰으로 정의한다. 컨테이너 쿼리 단위로 스크롤바가 있는 화면에서도 정확히 가운데 놓인다.

프로그램 목록·상세·정보 페이지·회원 공간·예매 페이지가 넓은 프레임을 공유한다. 본문은 72ch, 프로필 양식은 40rem, 예매 단계는 최대 72rem으로 읽기 폭을 구분한다. 제목·설명·버튼은 내용에 따라 자라며 목록은 가용 너비를 채운다. 포스터는 원본 비율을 보존한다. 좌석도는 48px 최소 조작 크기와 공간 관계를 유지하며 자체 영역에서만 가로로 스크롤한다.

## 직접 구성한 미니룸

`AccountMiniRoom` 안의 비공개 `MiniRoomArtwork`는 960×710 좌표계의 고정 SVG 장면을 TSX로 직접 작성한다. 마루·벽 몰딩·아치 창·커튼과 작은 무대·피아노·턴테이블·안락의자·카펫·책·화분·램프를 각각 배치했다. 무작위 생성과 외부 생성 서비스는 사용하지 않는다. 내부 렌더러는 상위 `AccountMiniRoom`에 속하며 공개 컴포넌트로 중복 집계하지 않는다.

실제 관심 공연 포스터 세 자리, 기존 테마·조명·이름·문구 편집과 저장을 유지한다. 긴 문구와 이름은 방 바깥의 흐름으로 이동해 장면을 가리지 않는다. 장면 내부 SVG 설명과 일반 UI는 분리하며 조작은 공통 버튼을 사용한다.

## 문구와 인증

히어로 문구는 작품의 몸짓·인물·빛을 짧게 소개한다. 불필요한 영문 장식과 반복되는 체험·비공식 고지는 실제 제품 화면에서 제거했다. 버전 선택 진입점과 보존된 구버전 파일은 유지했다. 예매 저장은 실제 동작대로 ‘예매 기록 저장’으로 표현한다.

Google 로그인 연결은 유지했으며 사용자가 실제 로그인 성공을 확인했다. 자동화 검사는 모의 제공자로 PKCE 교환·복귀·실패·로그아웃을 확인하며 개인의 Google 동의를 대신하지 않는다. 방과 관심 공연 등 기존 브라우저 저장 방식도 유지한다.

## 이력과 검증

작업 브랜치는 `codex/hero-room-layout`, 통합 브랜치는 `codex/integration`이다. Git 이름 충돌 때문에 `codex` 대신 `codex/integration`을 사용한다. 작업 → 통합 → `main`은 두 번 모두 `--no-ff`로 병합한다.

현재 작업의 단위 검사·브라우저 검사·정적 빌드·전체 미러 결과는 [검증 집계](verification/hero-layout-validation.json)에서 확인한다. 브라우저 검사는 320·390·768·1024·1440·1920·2560px의 주요 경로, 두 이웃 작품의 클릭·키보드·드래그·자동 재생, 모바일 좌석 흐름, 글자 확대를 포함한다. 화면 비교 이미지는 로컬 `.lemonade/hero-layout/`에 보관한다.
