## 검사 수정 이력

초기 통합 검사에서 모바일에 숨겨진 lazy 미리보기 이미지가 미로드로 판정됐다. 검사에서 숨겨진 이미지도 eager로 로드하고 decode하여 실제 자원 유효성을 확인하도록 보완했다. 교체된 이전 홈 안내 요소를 찾던 검사도 현재 화면 계약으로 갱신했다. 최초 실패 기록은 보존하고 실패한 그룹만 다시 실행했으며, 결과 집계는 경로/너비 및 검사 이름별 최신 결과를 사용한다.

기존 루트 v3 테스트의 경로 수 132 고정은 현재 v3의 138개 경로와 맞지 않았다. 이전 경로의 부분집합 보존 및 추가 굿즈 renderer를 확인하도록 테스트만 수정했다. v3 제품은 바꾸지 않았다.

Windows의 동적 ES-module import는 `pathToFileURL`을 사용하도록 검사 실행 환경을 보완했다. Node는 상위 package.json에 module type이 없어 자동 추론 경고를 출력하지만 검사 실패는 아니다.

## 확인 범위의 한계

로컬 Chrome headless에서 실제 DOM·입력·저장·애니메이션과 캡처를 검증했다. 물리 휴대폰 성능 또는 스크린리더 인증, 전체 HTML/WCAG 적합성 인증을 의미하지 않는다. 기본 HTML 구조는 렌더링된 label·중복 ID·중첩 조작 검사로 확인했다.

Toss/GS의 외부 라이브 브라우저 연결은 확장 연결 문제로 사용할 수 없었다. 공식 설명과 GDWEB 정적 캡처, 기존 lemonade 관찰 자료를 구분해 참고했다. 현재 사이트의 로컬 브라우저 검증은 별도로 수행했다. 출처와 제안 모션의 구분은 [참고 근거](sources/reference-motion-evidence.md)에 기록했다.

프로그램·날짜·회차·요금·예약은 비공식 시연 데이터다. 실제 결제·좌석 확보·기관 접수는 이루어지지 않는다.
