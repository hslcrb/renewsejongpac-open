## 레퍼런스에서 확인된 관계

### Toss: 공식 설명 + 아카이브 관찰

공식 개편 설명은 송금에서 일상·비즈니스로 이어지는 서비스들을 하나의 이야기로 잇는 목적을 밝힌다. 첫 스크롤의 실제 앱 장면과 이후 미래 장면은 이 설명의 근거이며, 이번 세션에서 직접 재생을 본 것은 아니다. [공식 기사](https://toss.im/newsroom/toss-new-homepage)

lemonade 아카이브 기록에서는 큰 단문, 조용한 설명문, 큰 여백, 넓은 미디어 영역, 기기·오브젝트·생활 장면이 반복된다. 일부 화면은 sticky 장면과 blur/translation/opacity reveal을 선언한다. 아카이브 재생 중 hydration 문제와 미완성 상태가 있었으므로 해당 기법의 작동·접근성·타이밍을 인증하는 자료로 쓸 수 없다. 모바일 렌더링도 아카이브 검토 당시 실패했다.

적용: 세종의 가치 문장 하나를 실제 공간이나 공연 이미지 하나가 설명하게 한다. 브랜드 컬러는 세종 체계를 유지한다. 폰 목업, 금융 UI, 유리 패널을 장식 목적으로 들이지 않는다. 일정·장소·예약 상태가 있는 페이지는 같은 정보의 비교와 행동을 우선한다.

### GS아트센터: 정적 편집 구성

이번에 내려받아 본 GDWEB 캡처에서는 로고가 왼쪽 위, 3개 메뉴가 왼쪽 중간 열, 사용자/검색/언어/전체메뉴 아이콘이 오른쪽 위에 있다. 상단 왼쪽 절반은 큰 여백을 두고 아래에 공연 분류·제목·일자를 배치한다. 오른쪽 절반은 넓은 세로 이미지 열과 좁은 이미지 열로 구성되어, 사진을 본 뒤 제목으로 시선이 이동한다. 네 칸의 읽기/보기 콘텐츠는 이미지 상단을 맞추되 각기 다른 높이를 유지하고, 이미지 아래에 분류·제목·날짜를 넣는다. 첫 칸은 흐려진 이미지 위에 `VIEW MORE`를 표시한 상태이나 그 발생 트리거는 정적 이미지로 확인할 수 없다. 얇은 가로선이 콘텐츠·연락/뉴스레터·법적 정보를 나눈다. [배포된 캡처](https://www.gdweb.co.kr/sub/filedata.asp?str_no=26820&sgbn=1)

이 직접 정적 관찰은 lemonade의 기존 분석과 일치한다. 흰 여백, 검정 제목, 회색 분류/날짜, 작품의 붉은 이미지가 대비를 만든다. 사진 위에 정보를 모두 겹치지 않고 텍스트의 영역을 확보하는 점이 세종 포털에 유용하다.

적용: 잡지형 사진 배치가 필요한 About·공간·읽을거리에는 비대칭을 제한적으로 사용한다. 공연 목록은 포스터 비율과 제목·날짜·장소·상태의 일관성을 유지한다. 메인 예매 행동을 비대칭 사진 뒤로 밀지 않는다. GS의 실제 라이브 모션을 확인하지 않았으므로 특정 효과를 GS의 특징이라고 주장하지 않는다.

## 세종 About 구성 제안 — 신규 설계

| 순서 | 페이지의 역할 | 시각/모션 제안 | 필수 내용과 최종 상태 |
| --- | --- | --- | --- |
| 1 | 세종의 정체성을 한눈에 전달 | 넓은 실제 공간 이미지 + 독립된 큰 한글 문장. 첫 진입 제목은 짧게 등장 | 제목·설명·다음 섹션 이동은 처음부터 접근 가능 |
| 2 | 공간을 경험으로 설명 | 이미지가 작은 프레임에서 넓은 프레임으로 자연스럽게 확장하는 대표 장면 1회 | 세종 자산만 사용. 정지 이미지에서도 내용 완결 |
| 3 | 예술 활동의 폭을 이해 | 공연·전시·교육을 서로 다른 사진 비율과 짧은 설명으로 배치 | 실제 카테고리와 유효한 연결. 임의 역사/성과 수치 금지 |
| 4 | 장소의 기억과 현재를 연결 | 검증된 연혁이 있으면 텍스트 기준선 옆에 연대와 사진. 데스크톱에서 설명 제목만 sticky 가능 | 모바일은 일반 문서 흐름. 긴 고정 구간 없이 전체 내용 읽기 가능 |
| 5 | 다음 행동으로 연결 | 큰 방문 장면 다음에 공연 보기·공간 안내·오시는 길 연결 | 행동은 스크롤 애니메이션 완료에 의존하지 않음 |

위 순서는 작업 방향 제안이다. 최종 콘텐츠와 IA는 사용자 자료에 맞춰 조정한다. Toss의 고유한 서비스 장면 순서를 재현하지 않는다.

## 접근 제한과 후속 검증

공식 Browser runtime 초기화 후 `getForUrl('https://toss.im/')`는 `No browser is available`, `browsers.list()`는 `[]`, Chrome 선택은 `Browser is not available: chrome`을 반환했다. 공식 진단 결과 Chrome은 실행 중이고 native-host manifest는 정상이지만 ChatGPT browser extension은 설치/활성화되어 있지 않다. 공식 Windows UI의 앱 목록은 조회 가능했으나 Browser 지침의 확장 연결 실패 후 별도 제어 우회 금지에 따라 독립 CDP·Playwright·Windows UI로 대체하지 않았다. 브라우저 설치/보안 설정은 변경하지 않았다.

따라서 **새 라이브 화면 스크린샷과 스크롤 동작 관찰은 없음**. 한국어 Toss 메인의 실제 첫 화면, GS아트센터의 현재 hover/scroll, 390px 모바일, reduced-motion 설정, 키보드와 영상 정지는 연결 가능한 공식 브라우저에서 후속 검증해야 한다. 이 제한은 제품의 구현 방향 제안을 막지는 않으며, 레퍼런스가 직접 관찰되었다는 주장만 제한한다.
