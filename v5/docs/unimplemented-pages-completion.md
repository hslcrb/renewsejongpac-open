## 자체 DB 처리

제품은 Supabase의 공개 카탈로그와 그 카탈로그에서 만든 정적 스냅샷을 읽습니다. `src/page-completion/content/`는 SQL 수입용 편집 원본이며 제품에서 직접 import하지 않습니다.

- 기존 `sejong_pages`의 대상 89개에만 `payload.completion`을 추가합니다. 나머지 9개 페이지와 기존 공연·장소·공지·미디어·회차 데이터는 유지합니다.
- 양식 16개 중 현재 접수 가능한 13개를 활성화했습니다. 확인되지 않는 옛 이벤트 2개와 접수 중 공고가 없는 채용 양식 1개는 닫았습니다.
- 문의·대관·단체관람·협력·후원·교육·구독·멤버십 상담은 계정에 연결한 접수번호로 저장·조회·취소합니다. 이메일 발송이나 기관 접수처 전달을 완료했다고 표시하지 않습니다.
- 굿즈 10개의 실제 상품명·표시 가격을 수입했습니다. 장바구니 수량과 구매 요청 합계는 서버가 결정합니다. 옵션·재고·배송·결제는 확정되지 않습니다.
- RLS와 좁은 GRANT를 함께 적용합니다. 비회원은 양식·상품만 읽으며 신청·장바구니는 본인만 조회합니다. 직접 INSERT/UPDATE 대신 검증 RPC를 사용합니다.
- 요청키 재시도는 같은 접수 결과를 반환합니다. 계정별 트랜잭션 잠금으로 수량 변경·주문·취소 경합을 처리합니다. 신청은 시간당 20건, 장바구니는 20종·상품별 20개로 제한합니다.
- 신청·장바구니의 90일 보관 기한은 실제 시간별 pg_cron 작업으로 집행합니다.

마이그레이션: `supabase/migrations/20261023061733_service_requests.sql`.
수입 원본 생성: `node scripts/seed-page-completion.ts`.
반복 수입은 내용이 바뀐 행만 UPDATE하여 기존 리비전 트리거가 불필요한 이력을 생성하지 않게 합니다.

## 검증과 증거

- `tests/page-completion.test.ts`: 89개 허용 경로·본문·출처·표·실제 기능 연결과 보호 경로 제외.
- `tests/service-requests.test.ts`: 동의·필드 소유권·날짜·수치 검증, 마감 상태, 브라우저 가격 주입 차단.
- `scripts/service-request-sql-check.ts`: 격리된 PostgreSQL에서 실제 양식 16개, 권한·소유권·검증·중복·보관 기한 및 동시 연결 검사.
- 운영 DB에서 같은 SQL 경계 검사를 트랜잭션 롤백으로 수행했습니다. 실제 회원의 데이터를 수정하거나 이메일을 보내지 않았습니다.
- `tests/service-requests-browser.ts`: 실제 Supabase SDK와 HTTP 대역으로 응답 실패 후 재시도, 계정 전환 중 늦은 저장, 수량·구매 요청·접수번호·취소, 대관 공간·날짜 전달을 확인합니다. 이 대역 검사를 운영 RLS 검사로 간주하지 않습니다.
- `tests/completed-pages-browser.ts`: 89개 전체를 320·1440px에서 검사하고 대표 화면에 390·768·1024px를 추가합니다. 검색·분류·FAQ·3곳 비교·월 선택·사이트맵도 조작합니다.
- 전체 단위 검사: 145개 중 144개 통과. 보존된 구버전 해시 라우터의 선택 브라우저 검사 1개는 기본 설정에 따라 제외됩니다. 새 v5 페이지 브라우저 검사는 별도로 실행합니다.

정적 서버의 전체 페이지 검사 211건과 신청 흐름 5건, 공통 컴포넌트 검사 12건이 통과했습니다. 정적 HTML 160개에서 참조 9,677건의 누락이 없었으며, 산출물 8,364개·52,181,825바이트가 미러와 일치합니다. 기존 70개 화면의 `<main>`도 변경 전과 바이트 단위로 일치합니다.

최종 수치는 `page-completion-verification.json`에 기록합니다. 신청·DB·빌드·kordoc 로그는 `v5/.lemonade/site-completion/`, 전수 브라우저 PNG와 링크 감사는 저장소 루트 `.lemonade/site-completion/`에 보관합니다. 개발 서버에서 한 번 관찰된 구문 오류는 동일 경로 재검사 5회 및 정적 전체 검사에서 재현되지 않았습니다. 원인을 확정했다고 보고하지 않습니다.
