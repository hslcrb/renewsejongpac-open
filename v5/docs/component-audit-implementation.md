- 네이티브 `data-text`에도 역할의 실제 글자 규격을 적용한다. 역할과 독립적인 size 축을 공유하며 컨트롤 16px와 기존 히어로·퀵메뉴 크기를 보존했다.

- 최소 16px, 기본 곡률 12px·flow 14px·패널 20px·compact 16px·dialog 28px, 옅은 안쪽 스트로크와 브랜드 색상을 유지했다.

## 본문과 콘텐츠 DB

본문·사실표·FAQ·연혁·지도 링크·다운로드·행동 블록을 CatalogPage에서 공통 컴포넌트로 렌더링한다. 공연 분류·공간·공지에는 실제 목록을 연결하고 검색은 공개 프로그램을 검색한다. 접수 API가 없는 기관 업무는 해당 공식 업무 페이지로 연결하며 신청 완료를 가장하지 않는다.

`CatalogRepository.loadPublishedCatalog()`와 `CatalogSnapshot`을 공개 계약으로 사용한다. 운영 DB→생성 스냅샷→정적 경로를 만들고 브라우저는 기존 공개 경로의 최신 내용을 갱신한다. 새 상세 경로는 재빌드로 생성한다. 게시 취소된 프로그램의 히어로·회차와 아직 정적 경로가 없는 ID는 브라우저에서 연결하지 않는다. 콘텐츠가 없는 히어로와 목록 축소도 안전하게 처리한다.

수입은 기존 ID를 보존하며 `ON CONFLICT DO UPDATE`와 변경 비교 조건을 사용한다. 같은 수입을 반복해도 행·revision·체크섬이 같았다. 원본 자료와 변경 이력은 비공개 스키마에 보존한다. 최종 revision 155개, 반복 수입 체크섬은 `71a6a8a9f8ffa16452685252cfad5387`로 일치한다. 내용이 같은 DB 재조회는 기존 스냅샷 바이트와 생성시각을 유지한다.

## 예약 서버

`getSessionSeats / holdSeats / confirmReservation / cancelReservation`은 Supabase RPC를 사용한다. 서버가 사용자·프로그램명·회차·좌석별 가격·합계를 결정한다. 직접 예약 INSERT와 가격 수정은 차단했다.

회차를 트랜잭션 잠금으로 보호해 여러 좌석을 전부 확보하거나 전부 롤백한다. 사용자·회차별 살아 있는 좌석 합계는 최대 4매다. 요청키와 내용을 보존해 재시도 시 같은 예약을 반환하고 만료를 연장하지 않는다. 상태는 5분 held→30분 reserved_unpaid→만료 또는 취소다. 취소와 만료가 겹쳐도 UI는 서버가 반환한 상태를 표시한다.

홈에서 선택한 날짜·회차·인원은 공통 예약 경로까지 전달한다. 화면 진입과 보류·확인 시 서버 재고를 확인한다. 교육도 존재하는 공통 예약 경로로 연결한다.

- 로컬 PostgreSQL의 100개 독립 보류 연결: 승자 1개, 나머지는 좌석 충돌.
- 확인 요청 100개 동시 재시도: 같은 만료시각 1개.
- 부분 예약 실패·가격 변조 방지·소유권·누적 4석·만료 정리·취소·쓰기 권한·강제 오류 시 전체 롤백 검증 통과.
- 운영 Supabase에서는 인증 role/claim을 설정한 트랜잭션 안에서 같은 RPC를 검증하고 전부 롤백했다. 시험 계정·공연·예약 잔존 0개.
- 실제 SDK를 사용하는 브라우저 HTTP fixture 14개를 별도로 통과했다. 방·관람노트·하트 저장, 응답 대기·실패·유실 재시도, 계정 전환과 늦은 응답, 상태·취소 재로드, 하트 채움과 알림 퇴장을 포함한다. 이 검사는 운영 RLS 증명과 구분한다.

실제 PG 결제·결제 완료·발권은 구현하지 않았다. 검증된 도면·회차·가격이 등록된 운영 자료에서 예약을 활성화한다.

## 실제 배포 파일의 가독성

실제 클라이언트 JS·CSS의 최적화 압축을 끄고 설명형 원본 경로와 번호를 사용한다. Next 내부 경로 키는 유지하고 캐시는 콘텐츠 기반 릴리스 폴더로 구분한다. 소스맵과 실제 소스·경로·바이트·gzip 크기의 매니페스트를 배포한다. 이미 축약돼 제공된 외부 라이브러리의 원래 식별자까지 복구한 것은 아니다.

배포 HTML은 4칸 들여쓰기로 출력한다. 본문에 의미 있는 공백과 React 주석·Flight 데이터·raw 스크립트는 보존한다. main-app 래퍼가 파싱 완료 후 기록된 서식 공백만 원복하고 원래 Next 초기화를 실행한다. charset·viewport 중복을 제거하고 theme-color는 중앙 컬러 정의를 참조한다.
