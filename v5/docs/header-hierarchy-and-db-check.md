# 헤더·푸터 위계와 DB 조회

디자인 토큰·공개 컴포넌트 계약·가이드 예제를 먼저 수정하고 Header·Footer에 연결했습니다. 색상과 일반 컨트롤 규격은 유지했습니다.

| 대상 | 공통 역할·그룹 | 표시 규격 |
| --- | --- | --- |
| GNB 5개 항목 | `SystemText`의 `navigation` 역할 | 18px · Medium 500 |
| 로그인·프로필 만들기·마이페이지·EN | `utility` 역할 | 16px · Medium 500 |
| 푸터 정책·디자인 시스템·고객지원·사이트맵 | `navigation` 역할 | 18px · Medium 500 |
| 헤더 검색·전체 메뉴 | `Icon`의 `header-action` 그룹 | 내부 SVG 28px · 원형 조작 영역 48px |
| 일반 Material 아이콘 | `general` 그룹 | 기존 인스턴스 크기 유지, 기본 24px |

18px 탐색과 16px 보조 탐색은 개별 이동값 없이 flex baseline으로 정렬합니다. 1440px 실측에서 GNB와 보조 메뉴 모두 기준선 y=52px였습니다. SVG는 `xMidYMid meet` 비율을 유지하며 두 아이콘의 원 중심 대비 가로·세로 오차는 0px입니다. 기존 모바일 메뉴 전환과 조작 영역도 유지합니다.

`header-action`은 TypeScript에서 `search`, `menu` 두 이름만 허용합니다. 크기는 `--icon-header-action-size`에서 관리하며 개별 `size` 덮어쓰기를 허용하지 않습니다. 런타임에서도 두 이름 밖의 아이콘은 일반 그룹으로 처리합니다. 검색·메뉴 아이콘의 모든 사용처를 일괄 확대하지 않습니다.

가이드의 타이포그래피 표와 실제 텍스트 예제, 아이콘 그룹 예제를 같은 계약에 연결했습니다. 활성 등록 50개와 제품 연결 50개, 가이드 전용·미사용 0개를 유지합니다.

## 검증

`tests/header-hierarchy.test.ts`로 역할·글자 크기 하한·아이콘 그룹 경계를 검사합니다. `tests/header-hierarchy-browser.ts`는 320·390·768·1024·1440px 실측, 가이드와 제품의 일치, 어두운 헤더, 검색 초점 복귀 및 메뉴 열기·닫기를 검사합니다. 캡처와 수치는 `v5/.lemonade/header-hierarchy/`에 기록합니다.

정적 빌드와 미러 생성이 완료됐습니다. 위 브라우저 검사 7건과 기존 공통 컴포넌트 브라우저 검사 12건이 통과했습니다. 제품 셸 159개 경로가 모두 같은 텍스트 역할과 헤더 아이콘 그룹을 사용합니다. 디자인 가이드 1개는 기존 문서 전용 셸을 유지합니다. HTML 160개의 정적 참조 9,677건에 누락이 없고, 산출물 8,364개가 미러와 일치합니다.

전체 단위 실행에서는 140건이 통과했고 선택적인 구버전 브라우저 검사 1건이 생략됐습니다. 새 CSS 직접 import로 단독 렌더링이 중단된 공통 컴포넌트 파일은 스타일을 루트의 공통 진입점으로 옮긴 뒤 해당 6개 검사를 재실행해 모두 통과했습니다. 아이콘 컴포넌트는 단독 서버 렌더링을 계속 지원합니다.
