# 마이페이지: 나의 작은 공연장

2026-10-21. 기존 v5의 팔레트·Wanted Sans·16px 기반·공통 컨트롤 규격을 사용한다. 공식 멤버십과 개인 취향 공간의 목적을 함께 충족하되, 공식 회원 등급·포인트나 실제 티켓을 임의로 만들지 않는다.

## 참고와 번역

- 사용자가 제공한 세종문화회관 마이페이지 화면: 프로필 요약, 관람예정 티켓, 관심 공연, 추천 공연과 실용적인 계정 메뉴의 순서를 참고했다. [공식 마이페이지](https://www.sejongpac.or.kr/portal/myPage/individual/list.do?menuNo=200479)는 비로그인 접근에서 로그인 화면으로 이동하므로 로그인 후 화면의 근거는 사용자 이미지다.
- 사용자가 제공한 싸이월드 미니홈피: 프로필 옆에 자기 공간이 있고, 한마디·미니룸·기록으로 취향이 쌓이는 관계를 참고했다. 캐릭터·Disney 이미지·배경을 복제하지 않는다. 미니룸은 세종 공연의 실제 포스터를 거는 독창적인 작은 극장 그림으로 다시 구성한다.
- [Letterboxd의 프로필·관람 기록](https://letterboxd.com/about/what-is-letterboxd/), [공개 프로필](https://letterboxd.com/austinlord/): 취향을 나타내는 포스터 선반과 날짜가 있는 감상 기록을 참고했다. 실제 브라우저에서 프로필·탭·기록의 관계를 확인했다. 캡처 당시 포스터 일부는 미로딩 상태였으므로 이미지 로딩을 검증한 근거로 삼지 않는다. 어두운 사이트 색상은 가져오지 않는다.
- [Cyworld 리디자인 목록](https://www.behance.net/d5c982e7)은 추가 탐색했으나 개별 상세 페이지가 403을 반환했다. 상세 화면을 새로 검토했다고 주장하지 않는다.

## 구성과 상태

- 왼쪽 프로필·관람 통계·공식 멤버십 안내, 오른쪽 여섯 개 실제 탭으로 구성한다. 모바일에서는 프로필과 본문을 재배치하고 탭은 내부 가로 탐색을 허용한다.
- 개인 공간: 세 가지 빛깔과 실제 조명 상태, 최대 세 개의 관심 공연 포스터. 관심 목록이 비어 있으면 추천 공연임을 명시한다.
- 예매: 요약형과 상세형이 같은 `AccountTicket`을 사용한다. 취소는 공통 대화상자에서 확인하며 취소·Escape에서는 기록을 바꾸지 않는다. 현재 기록은 체험 예매임을 분명히 한다.
- 관심: `ProgramCard`·`useFavorites`·공통 하트와 알림을 재사용한다. 관심 목록과 작은 공연장의 포스터는 같이 바뀐다.
- 관람노트: 실제 프로그램·관람일·최대 500자의 감상을 보관한다. 미래·잘못된 날짜와 빈 감상은 저장하지 않는다.
- 회원정보: 실제 OAuth 계정과 기존 체험 계정을 구분한다. 이름·연락처 저장과 로그아웃은 해당 계정 방식으로 처리한다. 인증받은 이메일을 임의로 변경하지 않는다.
- 꾸미기와 노트는 회원 식별자별 브라우저 저장소에 보관한다. 저장소가 거부되면 현재 창에서만 유지됨을 알린다. 다른 계정의 노트를 합치지 않는다.

## 컴포넌트 계약

`AccountExperience`가 인증·저장·페이지 상태를 조합하고, `AccountMembershipCard`, `AccountMiniRoom`, `AccountTicket`, `AccountDiary`는 역할별 UI를 담당한다. 버튼·입력·탭·필터·대화상자·관심 카드·알림은 기존 디자인 시스템 구현을 사용한다. 새 UI는 등록부와 실제 가이드 예제에 함께 연결한다.

## 검증 범위

320·390·768·1024·1440px, 긴 이름·한마디, 저장소 오류·손상, 빈 목록·여러 기록, 실제 탭 키보드·해시 이동, 꾸미기 적용·취소, 조명·하트 연동, 노트 저장·삭제, 체험 예매 취소, OAuth 콜백·로그아웃을 검증한다. 테스트에서 모의 인증으로 확인한 앱 동작과 실제 Google 계정 동의·복귀 검증은 구분한다. 운영 Google 설정은 [연결 안내](account-oauth-setup.md)를 따른다.

완료한 정적 빌드에서 브라우저 검사 94개와 단위 검사 96개가 통과했다. 보존용 검사 1개는 기본 실행에서 제외했다. HTML 160개, 산출물 8,307개와 루트 미러가 일치하며 이전 가입 안내 문구가 오래된 청크에 남지 않았음을 확인했다. [검증 집계](verification/account-space-validation.json)에 테스트별 결과를 연결한다.

새 체험 계정은 고정 로컬 ID를 발급한다. 같은 계정의 이름·이메일 수정은 이 ID를 보존하므로 공간과 노트가 유지된다. 새 계정 만들기는 별도 ID를 사용한다. 저장소 쓰기 실패 시에도 현재 앱 세션의 로그아웃을 유지하고, 실제 저장 실패는 화면에 알린다.
