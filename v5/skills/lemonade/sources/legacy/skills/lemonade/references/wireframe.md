# 원본 확대 해독과 섹션 문법

자료: 루트 `와이어프레임 실습.png`, **12992×4984**, 확인일 **2026-10-14**.
전체 보드와 원본 픽셀 행별 크롭을 보았고 Nav/hero의 펼침·닫힘 상태도 비교했다.
빠른 확인부터 푸터까지 43개 개별 조사 창을 추가로 확대했다. 중복 사례가 있어 43개 독립 사이트를 뜻하지 않는다.
비율은 시각적 근사값이다. 정확한 DOM·폰트·CSS 수치·동작을 정적 캡처로 증명하지 않는다.

## 큰 이미지를 읽는 순서

전체 구역 확인 → 제목/메타데이터/컨트롤을 포함한 행별 크롭 → 사례별 원본 픽셀 확대 → 전체 위계 재확인.
읽히지 않는 글자·사이트 이름은 미확인으로 둔다. 보드의 둥근 프레임과 그림자는 웹사이트 구성일 수 없다.
이미지 뷰어의 확대/크롭이나 로컬 브라우저를 쓴다. 브라우저가 없으면 픽셀 크롭을 사용하고 방법을 밝힌다.
원본을 덮어쓰거나 외부에 업로드할 필요는 없다.

| 원본 행 | 역할 | 관찰한 구성 | 선택 기준 |
| --- | --- | --- | --- |
| Nav | 탐색 | 투명/밝은/검은 GNB, 드롭다운, 전폭 메가메뉴, 브랜드/유틸리티 분리 | 정보 구조, 열기/닫기, 키보드, 모바일 |
| 첫 히어로 섹션 | 정체성과 행동 | 전폭 사진, 사진/예약 패널, 타이포+영상, 포스터군, 뉴스 분할 | 실제 자산·식별·주장·주 행동 |
| 두번째의 빠른 확인(요소) | 짧은 결정 경로 | 달력+일정, 예매, 2포스터, 서비스 선택, 고객 사례, 가격/예약 | 무엇을 지금 확인/선택하는가 |
| 세번째의 쇼 리스트(그리드 리스트) | 항목 탐색 | 포스터 레일, 뉴스 그리드/메이슨리, 프로젝트/자료 커버 | 비교 필드·인식·제목·필터 |
| 네번째의 와이드 쇼 리스트(그리드 리스트) | 넓은 정보 구성 | 2×2 풍경, 3×2 뉴스, 4상품/프로그램, 2:1:1 증거 | 우선순위와 비교 |
| 다섯번째의 납작와이드 쇼 리스트(리스트) | 낮은 깊이 정보 | 자료 1+2 이미지, 파트너 증거, 고객 사례, 연락/영상 | 읽는 길이와 콘텐츠 깊이 |
| 여섯번째의 종합 패널(종합) | 복합 정보 | 뉴스/뉴스레터 쌍, 6사진 편집, 소셜·영상·구독 | 주/보조 영역과 이동 목적 |
| Foot | 운영과 마무리 | 주소·정책·지원, 연락 행, 브랜드 이미지, 문의 폼, 다열 링크 | 마지막 행동·운영 정보 |

행은 고정 템플릿이나 카드 비율이 아니다. wide에도 세로 프로그램 카드가, flat에도 상품 그리드와 푸터가 있다.
필요한 역할만 선택한다. 같은 사례의 반복 배치를 독립 근거로 계산하지 않는다.

## 상세 관찰

- **Nav/hero:** 메뉴는 작은 드롭다운과 전폭 분류형이 공존한다. 사진 위 GNB는 펼침 때 배경과 대비가 바뀐다.
  호텔 예약 패널, 콘텐츠 포스터군, 의료의 주/보조 카드, 여행 비교 레일도 첫 화면을 구성한다.
- **quick 9개:** 특가 레일(3개+다음 일부), 연/월 달력+일정, WHAT'S ON 2포스터, 9분류+6서비스,
  5고객 사례, 주 기사+4최근 항목, 글/이미지 약 2:1 자료, 가격/포함사항/예약 상품, 달력+일정+좌석 표.
- **short 6개:** 포스터 레일, 뉴스 메이슨리, 4뉴스 커버, 2기능 데모, 5프로젝트 커버, 4자료 커버.
- **wide 9개:** 특가/5혜택, 청록 초대, 2×2여행, 사이드바+3×2뉴스, 4보안 서비스, 약 2:1:1특허,
  4제품, 편집 사진+2×2상품+의류, 4세로 프로그램.
- **flat 9개:** 보안·특허·상품·여행은 반복. 추가로 자료 1+2이미지, 파트너/연락, 로고 행/행동,
  주 고객 사례+3보조 사례, 넓은 영상+세로 포스터/스폰서.
- **panel 3개:** 2×2뉴스+큰 뉴스레터, 약 1:2:1의 6사진 모자이크, 태그/플레이리스트/릴/영상/구독.
- **footer 7개:** 검은 운영 정보, 연락 행, 빨간 초대, 브랜드 사진/사무소, 보라 문의 폼, 4유틸리티 열, 기관 정책/주소/등록 정보.

## 실사용으로 옮기기

한글은 실제 글꼴의 받침·행간·문장부호·어절을 확인한다. 영어 글자/단어 예산을 그대로 옮기지 않는다.
비교하는 항목은 필드를 정렬하고 편집 우선순위가 있으면 주/보조 크기를 달리한다.
포스터의 이미지 속 제목에만 의존하지 않고 접근 가능한 실제 이름과 날짜를 제공한다.
캡처의 작은 글씨·낮은 대비·잘림까지 답습하지 않는다. 390px에서 필수 내용을 보존하는 새 구성이 필요하다.
캐러셀과 탭의 존재는 관찰했지만 작동은 별도 확인해야 한다.
NOL 방문 안내 아이콘, 전주 일정 구분선, MG 서비스 바로가기, GS 다열 운영 푸터는 기능적 반복 구성의 대조 사례다.
[GDWEB 카탈로그](../library/reference-cases.json)에서 확인한다.
